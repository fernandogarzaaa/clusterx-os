Configuration guide

Simulator (default)
No setup. Messages appear in the lead thread inside this app. Set OUTBOUND_CHANNEL=simulator (the default) to keep it.
Twilio (SMS / WhatsApp)
Set TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN and TWILIO_FROM (your Twilio number, or a whatsapp:+1415... sender for WhatsApp). The adapter POSTs to api.twilio.com/2010-04-01/Accounts/.../Messages.json with HTTP basic auth. Without these, every send raises a clear ConfigurationError instead of failing silently.
WhatsApp Cloud API
Set WHATSAPP_TOKEN (a Meta system-user access token) and WHATSAPP_PHONE_NUMBER_ID. The adapter POSTs to graph.facebook.com/v21.0/<phone-id>/messages with a Bearer token. Note: template messages are required outside the 24-hour customer-service window; plain-text sends work inside it.
Inbound webhook
External systems can create leads via POST /api/webhooks/leads with header X-API-Key. The key is WEBHOOK_API_KEY (default dev-webhook-key, change it in production).
